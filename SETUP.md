# TradeSignal AI — Local Setup Guide

Run the full app on any computer (Windows / macOS / Linux).

## Prerequisites
1. **Python 3.11+** — https://python.org/downloads
2. **Node.js 20+** — https://nodejs.org
3. **pnpm** — Run `npm install -g pnpm` once after installing Node

## Step 1 — Install Python dependencies
```bash
cd artifacts/api-server/trading
pip install -r requirements.txt
```
This installs FastAPI, yfinance, pandas, numpy, ta, websockets, httpx, scipy, and uvicorn — everything the 9 trading agents and the Kelly sizer need.

## Step 2 — Install Node dependencies
From the **repo root** (one level above `artifacts/`):
```bash
pnpm install
```

## Step 3 — Start both servers (in two terminals)

**Terminal 1 — Backend API (Port 8080):**
```bash
cd artifacts/api-server/trading
python server.py
```
You should see `Uvicorn running on http://0.0.0.0:8080`.

**Terminal 2 — Dashboard UI (Port 8081):**
```bash
cd artifacts/mockup-sandbox
pnpm dev --port 8081
```
You should see `Local: http://localhost:8081/`.

## Step 4 — Open the dashboard
```
http://localhost:8081/
```
Click any symbol or type a ticker and hit **Analyze**.

---

## Generated data files (already included in the repo)

These JSON files are generated by back-testing scripts and ship with the repo so the app works out of the box. To **regenerate** them with fresh market data (recommended monthly):

```bash
cd artifacts/api-server/trading

# Refresh per-volatility-regime hit-rate stats (used by the Kelly sizer)
python tests/compute_regime_stats.py

# Refresh per-stock historical accuracy badge (shown in the dashboard)
python tests/compute_track_record.py
```

Each takes ~1–2 minutes (downloads 2 years of data per symbol).

## Verify the install

Run the unit tests — should print **46 passed, 0 failed**:
```bash
cd artifacts/api-server/trading
python tests/test_agents.py
```

Run a back-test over the default basket (~30 seconds):
```bash
python tests/backtest.py
```

## Troubleshooting

| Problem | Fix |
|---|---|
| `ModuleNotFoundError: No module named 'fastapi'` | You're in the wrong Python env — re-run `pip install -r requirements.txt` |
| `pnpm: command not found` | Run `npm install -g pnpm` |
| Browser shows "Cannot connect" | Make sure BOTH terminals are running (API on 8080, UI on 8081) |
| `track_record.json: file not found` warnings | Run `python tests/compute_track_record.py` once |
| Dashboard loads but no signals appear | Check Terminal 1 for yfinance errors — Yahoo may be rate-limiting; wait a minute |
| Port 8080 or 8081 already in use | Kill the other process or pick a different port (`PORT=9000 python server.py`) |

## Push to GitHub

### From Replit (first time):
1. Create a new empty repo at https://github.com/new (no README)
2. In the Replit shell:
```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

### On your laptop (after cloning):
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```
Then follow steps 1–4 above.
